# Glossary

- Kustomize: builds Kubernetes manifests from a base plus per-environment overlays.
- Overlay: a folder that changes only what differs for one environment.
- ArgoCD: watches Git and makes the cluster match it.
- Kyverno: enforces policies on Kubernetes resources.
- HPA: horizontal pod autoscaler, adds or removes pods based on load.
- PDB: pod disruption budget, keeps a minimum number of pods running during maintenance.
